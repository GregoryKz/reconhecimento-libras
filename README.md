# Projeto Libras – Python

Este repositório contém um **projeto em Python voltado à Libras (Língua Brasileira de Sinais)**, desenvolvido para fins de estudo e prática em processamento de sinais e acessibilidade digital.  

O foco é criar ferramentas que possam **interpretar, organizar ou exibir sinais de Libras**, usando Python e recursos de manipulação de dados, imagens ou vídeos.

---

## 🎯 Objetivos do Projeto

- Explorar Python aplicado à Libras e acessibilidade  
- Criar métodos para armazenar, consultar ou exibir sinais  
- Desenvolver scripts que manipulem dados de vídeos ou imagens  
- Preparar base para futuras aplicações em interface web ou mobile  

---
